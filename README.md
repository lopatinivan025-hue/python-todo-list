# Консольный менеджер задач (To-Do List)

Итоговый проект для "ИТ школы Ростелеком" (Кейс 7).

## Описание
Программа на Python для ведения персонального списка задач через консоль. Реализует добавление, удаление, отметку выполнения и просмотр задач со сложной сортировкой.

## Особенности
* **Хранение данных:** Задачи автоматически сохраняются в файл `tasks.json`.
* **Валидация ввода:** Защита от пустых строк, неверных форматов дат (ДД.ММ.ГГГГ) и ввода прошедшего времени.
* **Умная сортировка:** Задачи выводятся по сроку выполнения, приоритету и статусу активности.

## Запуск
Требуется Python 3.9+. Запустите скрипт командой:
`python main.py`
